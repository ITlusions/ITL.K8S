# Freedom Internet Fiber VPN MTU Optimization

## Overview
MTU optimization for Freedom Internet fiber connections with VPN access to Kubernetes clusters.

## Freedom Internet Fiber Specifications
- **Connection Type**: Direct Ethernet over Fiber (no PPPoE overhead)
- **Standard MTU**: 1500 bytes (Full Ethernet frame)
- **Provider Profile**: "Freedom Glasvezel" in FRITZ!Box
- **Network Types**: XGSPON (KPN), GPON (via ONT), Delta Netwerk, aQuestora

## VPN MTU Values for Fiber

```bash
# Fiber Base MTU
Base MTU: 1500 bytes (Full Ethernet, no PPPoE overhead)

# VPN Overhead Calculations
L2TP/IPSec: ~60 bytes overhead
SSTP: ~50 bytes overhead
IKEv2: ~80 bytes overhead

# Optimal VPN MTU Values for Fiber
L2TP/IPSec: 1440 bytes (1500 - 60)
SSTP: 1450 bytes (1500 - 50)
IKEv2: 1420 bytes (1500 - 80)
```

## EdgeRouter Fiber Configuration

```bash
# EdgeRouter CLI Configuration for Freedom Internet Fiber
configure

# Set WAN interface for fiber connection
set interfaces ethernet eth0 description "Freedom Internet Glasvezel"
set interfaces ethernet eth0 mtu 1500
set interfaces ethernet eth0 address dhcp

# VLAN Configuration (if required)
# GPON networks may use VLAN 6 or 10
set interfaces ethernet eth0 vif 6 description "Freedom Internet VLAN 6"
set interfaces ethernet eth0 vif 6 mtu 1500
set interfaces ethernet eth0 vif 6 address dhcp

# MSS Clamping for VPN optimization
set firewall options mss-clamp interface-type ethernet
set firewall options mss-clamp mss 1460

# Default route
set protocols static route 0.0.0.0/0 next-hop dhcp eth0

commit
save
```

## Advanced MSS Clamping for Fiber

```bash

set firewall name WAN_LOCAL rule 10 action accept

set firewall name WAN_LOCAL rule 10 tcp flags SYN
set firewall name WAN_LOCAL rule 10 tcp mss 1440

```

## Windows VPN Client Configuration

```powershell
# PowerShell script for Windows VPN MTU optimization on Fiber (Run as Administrator)

# Set optimal MTU for VPN adapter
$VPNAdapter = Get-NetAdapter | Where-Object {$_.InterfaceDescription -like "*VPN*" -or $_.Name -like "*VPN*"}
if ($VPNAdapter) {
    netsh interface ipv4 set subinterface $VPNAdapter.InterfaceIndex mtu=1440 store=persistent
    Write-Host "VPN MTU set to 1440 bytes for Freedom Internet Fiber"
}

# Registry settings for TCP optimization
$RegistryPath = "HKLM:\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters"
Set-ItemProperty -Path $RegistryPath -Name "Tcp1323Opts" -Value 3 -Type DWord
Set-ItemProperty -Path $RegistryPath -Name "TcpWindowSize" -Value 131072 -Type DWord
Set-ItemProperty -Path $RegistryPath -Name "TcpAckFrequency" -Value 1 -Type DWord
Set-ItemProperty -Path $RegistryPath -Name "EnablePMTUDiscovery" -Value 1 -Type DWord

Write-Host "Windows TCP optimization completed - restart required"
```

## MTU Testing

```powershell
# Test optimal VPN MTU for fiber connection
function Test-FiberMTU {
    $TestHost = "8.8.8.8"
    $FiberMTU = 1440  # L2TP/IPSec optimal for fiber
    $TestSize = $FiberMTU - 28  # Account for IP/ICMP headers
    
    Write-Host "Testing fiber VPN MTU: $FiberMTU bytes..."
    $Result = Test-Connection -ComputerName $TestHost -Count 3 -BufferSize $TestSize -DontFragment -ErrorAction SilentlyContinue
    
    if ($Result) {
        Write-Host "✓ MTU $FiberMTU - Success" -ForegroundColor Green
    } else {
        Write-Host "✗ MTU $FiberMTU - Failed" -ForegroundColor Red
    }
}

Test-FiberMTU
```
